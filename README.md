# MOTO'DI GO Admin Dashboard

## Current Delivery State

This repository currently delivers a mock Astro/Tailwind operations dashboard. The UI uses local mock data and is not yet connected to the API Gateway, authentication, RBAC, moderation workflows, KYC review, pricing administration or KPI export backends.

Do not count this dashboard as delivered for the business features in the product backlog until the follow-up admin/RBAC/API tickets are implemented and tested end to end.
